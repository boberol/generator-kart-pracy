# Czcionki

Czcionki są dołączone do strony (bez Google Fonts), dzięki czemu strona działa szybciej, także bez internetu, i nie wysyła danych do zewnętrznych serwerów.

| Plik | Czcionka | Autorzy | Licencja |
| --- | --- | --- | --- |
| `nunito-*.woff2` | Nunito (zmienna grubość 400–800) | The Nunito Project Authors | SIL OFL 1.1 |
| `andika-*.woff2` | Andika | SIL International | SIL OFL 1.1 |
| `playwrite-pl-300.woff2` | Playwrite Polska | The Playwrite Project Authors (TypeTogether) | SIL OFL 1.1 |

Pełny tekst licencji SIL Open Font License 1.1: `OFL.txt` (wzór dla Nunito; Andika i Playwrite są na tej samej licencji).
